# Спектральная структура NVG: точные тождества, устойчивость и границы обратного восстановления

Исследовательский отчёт · 10 сентября 2026 года

## Краткий результат

В принятой длинноволновой модели отклика плотной материи получена общая рекурсия спектральных моментов. Из неё следуют точные формулы для двух следующих моментов, положительного определителя моментов и связи между медленной сжимаемостью и быстрым упругим откликом. Независимый путь через самосопряжённый кинетический оператор воспроизводит те же соотношения и объясняет положительность спектра. Выведено также тождество: вычет коллективного полюса равен производной его положения по параметру взаимодействия \(F_0\).

Это новые проверяемые результаты для данного расчётного направления проекта. Они не являются подтверждением NVG экспериментом или самостоятельными новыми законами природы. Связи спектральных сумм с различными упругими жёсткостями известны в теории Ферми-жидкости; существенны корректная специализация, учёт векторной инерции и независимые проверки именно используемого отклика. Первичный пример такого различения — работа Коломийца, Лукьянова и Худенко, особенно уравнения 49–50. [Kolomietz et al., 2007](https://arxiv.org/abs/0706.0670).

Не менее важен отрицательный результат: два отношения спектральных моментов не определяют единственную микроскопическую теорию. При дополнительных угловых взаимодействиях они восстанавливают уже другие комбинации параметров. Поэтому красивое внутреннее совпадение нельзя подменять внешней проверкой.

## 1. Что именно рассматривается

Используется уже принятая равновесная ветвь скалярно-векторной модели и её бесстолкновительный линейный отклик. Параметры действия не изменяются. Фиксированы знак внешнего источника, причинное граничное условие и связь векторной обратной реакции с параметрами Ландау:

\[
\delta\epsilon_{\mathbf p}=\ldots+U,\qquad
\delta n=\chi U,\qquad
F_1=-\frac{3r}{1+r}.
\]

Временная зависимость — \(e^{-i\omega t}\). Положительная частота соответствует \(\omega>0\). Определим

\[
z=\frac{\omega+i0}{kv_F},\quad
A=1+r,\quad a_0=1+F_0,
\]

\[
L(z)=\frac z2[\log(z+1)-\log(z-1)]-1,
\]

\[
g(z)=\frac{\chi(z)}{N_F}
=\frac{L(z)}{1-(F_0-3rz^2)L(z)}.
\tag{1}
\]

Разность логарифмов берётся на ретардированной ветви. Выбор другого листа по желаемому числу полюсов не является допустимой проверкой модели. Рабочая область здесь: \(F_0>-1,\ r\ge0\), а высшие угловые параметры \(F_{\ell\ge2}\) отсутствуют в принятом замыкании.

Это эффективная длинноволновая теория. Для интерпретации её разложения по частоте требуется согласованное окно \(kv_F\ll|\omega|\), но частота остаётся ниже исключённых массивных полевых степеней свободы. Формальное интегрирование её эффективного спектра до бесконечности по \(z\) не превращает полученные суммы в точные микроскопические суммы всей релятивистской материи. Конечные длины волн, столкновения и дополнительные высокоэнергетические каналы требуют отдельного вывода.

## 2. Спектр, нормировка и уже установленные опорные суммы

Положительная спектральная плотность определяется как

\[
\overline S(s)=-\frac1\pi\operatorname{Im}g(s+i0),\qquad s>0.
\]

Внутри непрерывного спектра \(0<s<1\), положив
\(x=\frac s2\log\frac{1+s}{1-s}-1\) и \(q=F_0-3rs^2\), получаем

\[
\overline S_{\rm cont}(s)=
\frac{s}{2[(1-qx)^2+(q\pi s/2)^2]}.
\tag{2}
\]

Если \(F_0>3r\), имеется отдельный положительный полюс \(s_p>1\) с вычетом \(R>0\). Его вклад в спектр — \(R\delta(s-s_p)\). При \(F_0\le3r\) такого полюса нет. Порог возникновения отдельного пика и граница статической устойчивости — разные условия.

Моменты определены без дополнительной нормировки под целевой ответ:

\[
m_j=\int_0^1s^j\overline S_{\rm cont}(s)\,ds
+\mathbf1_{F_0>3r}R s_p^j.
\tag{3}
\]

Ранее проверенные опорные формулы:

\[
m_{-1}=\frac1{2(1+F_0)},\qquad
m_1=\frac1{6(1+r)},
\]

\[
c_{\rm first}^2=v_F^2\frac{m_1}{m_{-1}}
=\frac{v_F^2(1+F_0)}{3(1+r)}.
\tag{4}
\]

В частности, при выбранном знаке источника статический отклик отрицателен:
\(g(0)=-1/(1+F_0)=-2m_{-1}\). Потеря знака здесь нарушает термодинамическое соответствие, даже если отдельная кривая выглядит гладкой.

## 3. Общая рекурсия: много формул из одного отклика

Для больших \(|z|\)

\[
L(z)=\sum_{n\ge1}u_nz^{-2n},\qquad
u_n=\frac1{2n+1},
\]

\[
g(z)=\sum_{n\ge1}c_nz^{-2n},\qquad
c_n=2m_{2n-1}.
\]

Подстановка в (1), без интегральной подгонки коэффициентов, даёт

\[
\boxed{
A c_n=u_n+\sum_{j=1}^{n-1}d_jc_{n-j},\qquad
d_j=F_0u_j-3ru_{j+1}.
}
\tag{5}
\]

Пустая сумма при \(n=1\) равна нулю. Это единая порождающая формула нечётных положительных моментов данного отклика. Она не вводит новых параметров и позволяет проверять больше свойств спектра, чем только статическую сжимаемость и первый момент.

Первые новые результаты:

\[
\boxed{m_3=\frac{9+5F_0}{90(1+r)^2}},
\tag{6}
\]

\[
\boxed{
m_5=\frac{675+630F_0+175F_0^2+108r}
{9450(1+r)^3}.
}
\tag{7}
\]

Особенно простой результат получается после сокращения большого числа членов:

\[
\boxed{m_1m_5-m_3^2=\frac1{525(1+r)^3}>0.}
\tag{8}
\]

Положительность следует также из неравенства Коши–Буняковского для положительной спектральной меры. Здесь вычислено не только направление неравенства, но и его точное значение в принятом замыкании. Поэтому (8) — дополнительная проверка формы спектра. Совпадение двух старших интегралов с (6)–(7) значительно содержательнее совпадения одной нормировки.

Есть простое следствие: весь отклик нельзя точно заменить одним идеальным резонансом при конечном \(r\). Для единственной линии \(R\delta(s-s_p)\) определитель \(m_1m_5-m_3^2\) тождественно равен нулю, тогда как (8) строго положителен. Следовательно, распределённая спектральная часть — необходимая часть решения, а не необязательная поправка к красивому единственному пику.

Однако интегральная проверка сама по себе может не заметить потерю экспоненциально слабого отдельного пика: его вклад может быть меньше заданной абсолютной погрешности. Поэтому в расчётной проверке отдельно контролируются существование, знак, величина зазора и вычета полюса.

### Семейство инвариантов всех порядков

Сокращение \(F_0\) в (8) не случайно. Пусть

\[
\mathcal H_N=\det[m_{2(i+j)+1}]_{i,j=0}^{N-1},
\qquad N=1,2,\ldots.
\]

Для того же замыкания получается общая формула

\[
\boxed{
\mathcal H_N=
\left[\frac1{6A}\right]^N
\prod_{j=0}^{N-2}\beta_j^{\,N-1-j}
=\frac{C_N}{(1+r)^{2N-1}}>0,
}
\tag{8a}
\]

где пустое произведение равно единице, \(C_N\) — точное рациональное число, не зависящее от \(F_0,r\), и

\[
\beta_j=
\frac{(2j+2)^2(2j+3)^2}
{(4j+3)(4j+5)^2(4j+7)}
\begin{cases}
A^{-1},&j=0,\\
1,&j\ge1.
\end{cases}
\]

В частности,

\[
\mathcal H_1=\frac1{6A},\qquad
\mathcal H_2=\frac1{525A^3},\qquad
\boxed{\mathcal H_3=\frac{32}{22920975A^5}.}
\tag{8b}
\]

Для вывода используется матричное представление из раздела 7. Нормированные моменты \(m_{2j+1}/m_1\) равны \(\langle1|(B^2)^j|1\rangle\). В нечётном подпространстве \(|1\rangle,|3\rangle,\ldots\) соседние элементы \(B^2\) равны \(b_{2j+1}b_{2j+2}\), то есть их квадраты — \(\beta_j\). Определитель Грама степеней переменной выражается произведением норм ортогональных многочленов, откуда следует (8a). Параметр \(F_0\) входит в первый диагональный элемент этой матрицы, но не в произведение её соседних элементов, поэтому полностью сокращается.

Общая связь определителей моментов и коэффициентов трёхчленной рекурсии — известная математика, а (8a) — её специализация к нашему отклику. В численном применении важно учитывать плохую обусловленность высоких определителей; большая точность символического тождества не означает устойчивого восстановления по шумным данным. [NIST DLMF, §18.2(ix), уравнение (18.2.30)](https://dlmf.nist.gov/18.2#ix).

Дополнительно к общему выводу проведена точная рациональная проверка \(N=1,\ldots,5\) для трёх разных пар \((F_0,r)\). Формула \(\mathcal H_3\) независимо проверена символически при произвольных \(F_0,r\). Все \(\mathcal H_N>0\), поэтому никакое конечное число идеальных линий не может точно воспроизвести всю иерархию этого эффективного спектра. При фиксированной нормировке разные порядки дают согласованные проверки одного \(r\), но не новые независимые экспериментальные подтверждения.


## 4. Медленное сжатие и быстрый упругий отклик

Введём величину, определённую через отношение моментов:

\[
c_{\rm scale}^2:=v_F^2\frac{m_3}{m_1}.
\]

Тогда из (4) и (6)

\[
\boxed{
c_{\rm scale}^2-c_{\rm first}^2
=\frac{4v_F^2}{15(1+r)}>0.
}
\tag{9}
\]

Простыми словами: медленная деформация позволяет распределению частиц перестроиться, тогда как быстрый отклик сохраняет дополнительную угловую деформацию поверхности Ферми. Поэтому две характеристики жёсткости могут различаться даже при одних и тех же параметрах вещества.

Термин \(c_{\rm scale}\) обозначает спектральную характеристику — не измеренную скорость сигнала. Его нельзя автоматически отождествлять с точной фазовой скоростью отдельного нулевого звука \(v_Fs_p\), групповой скоростью или предельной скоростью распространения фронта.

Это различие можно увидеть внутри самой модели. При \(F_0=3{,}01,r=1\) полюс существует и \(s_p>1\), но \(c_{\rm scale}^2/v_F^2=0{,}801666\ldots<1\). Отношение моментов усредняет весь спектр, а не выделяет положение его слабого отдельного пика.

При принятой нормировке
\(N_F=3n/(E_Fv_F^2)\), \(p_F=E_Fv_F\), \(\mu=E_F(1+r)\).
Угловой интеграл для сдвиговой деформации даёт кинетическую жёсткость данного бесстолкновительного замыкания

\[
G_{\rm kin}=\frac{N_F(p_Fv_F)^2}{15}
=\frac{np_Fv_F}{5},
\]

и алгебраически (9) переписывается как

\[
c_{\rm scale}^2-c_{\rm first}^2
=\frac{4G_{\rm kin}}{3n\mu}.
\tag{10}
\]

Здесь инерция — \(n\mu\), а не произвольно подставленная плотность свободных масс. Это независимо полученная специализация NVG. Для сравнения, у Conti–Vignale в трёх измерениях уравнение (3.25) даёт \(G=np_Fv_F(1+F_2/5)/5\), после использования принятой в той работе галилеевой связи масс; инерция в их уравнениях — \(mn\). При \(F_2=0\) сдвиговая величина совпадает с приведённым угловым интегралом, но нерелятивистская статья не выводит замену \(mn\) на \(n\mu\). [Conti & Vignale, 1999, уравнения (2.1), (2.7), (3.25)](https://mospace.umsystem.edu/server/api/core/bitstreams/49ef2871-ce7b-4ffa-b46f-3f32c5ae7220/content).

Интерпретация \(G_{\rm kin}\) как полного физического модуля сдвига NVG по-прежнему требует согласованного тензорного источника напряжений и учёта взаимодействий за пределами \(F_0,F_1\). Это не рассчитанная вязкость и не доказательство распространения поперечной волны в полном веществе.

## 5. Спектральная форма и обратная задача

Нормируем положительную меру следующим образом:

\[
dP(s)=\frac{\overline S(s)\,ds}{s\,m_{-1}},
\qquad X=s^2.
\]

Тогда

\[
\mathbb E X=\frac{m_1}{m_{-1}},\qquad
\operatorname{Var}X=\frac{4(1+F_0)}{45(1+r)^2},
\]

\[
\boxed{
Q_-:=\frac{\operatorname{Var}X}{(\mathbb E X)^2}
=\frac{m_{-1}m_3}{m_1^2}-1
=\frac4{5(1+F_0)}.
}
\tag{11}
\]

В относительном разбросе параметр \(r\) полностью сокращается. Это не означает, что векторное взаимодействие отсутствует в самом спектре: оно меняет его частотные характеристики и другие отношения моментов.

Определим также \(Q_+=m_1m_5/m_3^2-1\). Для данного замыкания:

\[
\boxed{
F_0=\frac4{5Q_-}-1,\qquad
r=\frac{7(5F_0+9)^2Q_+}{108}-1.
}
\tag{12}
\]

Оба отношения не меняются при общем масштабировании амплитуды и частотной оси спектра. Это полезное свойство для сравнения форм, но оно не устраняет необходимость измерить весь релевантный спектральный вес и оценить фон, погрешности и потерянные каналы. При малых \(Q_\pm\) вычитание единицы и обратные зависимости ухудшают обусловленность задачи.

Уточнение о погрешностях: если уже известны относительные ошибки самих положительных \(Q_\pm\), локальная передача ошибок проста:

\[
d\ln(1+F_0)=-d\ln Q_-,\qquad
d\ln(1+r)=d\ln Q_+
-\frac{10(1+F_0)}{5F_0+9}\,d\ln Q_-.
\]

Последний коэффициент лежит между нулём и двумя при \(F_0>-1\). Главная практическая трудность — получить малые \(Q_\pm\) с достоверной относительной точностью из разностей измеренных отношений моментов, а не само алгебраическое обращение в этих логарифмических координатах.

### Явный контрпример уникальности

Рассмотрим только математическое расширение угловой энергии, не добавляя новые параметры в физическую модель проекта:

\[
a_0=1+F_0,\quad a_1=\frac1{1+r},\quad
a_2=1+\frac{F_2}{5},\quad a_3=1+\frac{F_3}{7}.
\]

При положительных \(a_\ell\) остаётся положительный кинетический оператор, но уже

\[
Q_-=\frac{4a_2}{5a_0},\qquad
m_1m_5-m_3^2=\frac{a_1^3a_2^2a_3}{525}.
\tag{13}
\]

Если ошибочно применить к этим данным усечённую формулу (12), она вернёт

\[
\boxed{
F_{0,\rm inferred}=\frac{1+F_0}{1+F_2/5}-1,\qquad
r_{\rm inferred}=(1+r)(1+F_3/7)-1.
}
\tag{14}
\]

Например, математический набор \(F_0=4,r=1,F_2=5,F_3=7\) будет интерпретирован по двум отношениям как \(F_0=1{,}5,r=3\). Это не ошибка вычислений: двух наблюдаемых недостаточно для восстановления четырёх параметров. Таким образом, формула (12) проверяема и полезна, но условна; она не идентифицирует универсальную теорию.

## 6. Положение и вес коллективного пика связаны точно

Пусть \(D(s)=1-(F_0-3rs^2)L(s)\) и \(D(s_p)=0\). Для простого полюса

\[
D_s=6rsL-(F_0-3rs^2)L',\qquad
R=\frac{L(s_p)}{D_s(s_p)}.
\]

Неявное дифференцирование сразу даёт

\[
\boxed{
\frac{\partial s_p}{\partial F_0}=R,\qquad
\frac{\partial s_p}{\partial r}=-3s_p^2R.
}
\tag{15}
\]

Это точная связь двух разных характеристик того же отклика: положения и веса отдельного пика. При фиксированном \(r\) увеличение \(F_0\) сдвигает пик вверх; при фиксированном \(F_0\) увеличение \(r\) — вниз. Знаки относятся к безразмерной частоте \(s_p\); изменение физической скорости \(v_Fs_p\) дополнительно включает изменение \(v_F\).

На реальной равновесной ветви, при \(x=\ln n\),

\[
\boxed{
\frac{ds_p}{dx}
=R\left(\frac{dF_0}{dx}-3s_p^2\frac{dr}{dx}\right).
}
\tag{16}
\]

Производные параметров здесь получаются из фактических равновесных уравнений. Их нельзя восстановить по одному акустическому отношению \((1+F_0)/(1+r)\).

Около порога \(\Delta=F_0-3r\to0^+\) зазор \(h_p=s_p-1\) экспоненциально мал:

\[
\log h_p\sim\log2-2-\frac2\Delta,\qquad
R\sim\frac{2h_p}{\Delta^2}.
\]

Поэтому практически вычисляется

\[
\frac{d\log h_p}{dx}
=\frac{R}{h_p}\left(F_{0,x}-3s_p^2r_x\right).
\]

При \(F_0=3{,}01,r=1\) вычет составляет около \(7{,}49\cdot10^{-84}\). Независимые разности решённого логарифма зазора воспроизводят обе производные (15); обычное вычитание округлённых значений \(s_p\) могло бы ошибочно дать ноль. Отсутствующему полюсу не назначается нулевая производная: соответствующая характеристика отсутствует.

## 7. Почему стационарная модель устойчива в своей области

Пусть \(u=\cos\theta\), скалярное произведение равно \(\frac12\int_{-1}^{1}\), а оператор квадратичной энергии

\[
\mathcal A=I+F_0|1\rangle\langle1|+F_1|u\rangle\langle u|.
\]

Его собственные коэффициенты в ортонормированном базисе Лежандра:

\[
a_0=1+F_0,\qquad a_1=\frac1{1+r},\qquad a_{\ell\ge2}=1.
\]

В принятой области они положительны. Оператор переноса \(u\mathcal A\) подобен самосопряжённому

\[
B=\mathcal A^{1/2}u\mathcal A^{1/2}.
\]

Матрица \(B\) имеет нулевую диагональ и соседние элементы

\[
b_\ell=
\frac{(\ell+1)\sqrt{a_\ell a_{\ell+1}}}
{\sqrt{(2\ell+1)(2\ell+3)}}.
\tag{17}
\]

Тот же отклик выражается через резольвенту:

\[
\boxed{
g(z)=\frac{z\langle0|(z-B)^{-1}|0\rangle-1}{a_0},
\qquad
2m_{2j-1}=\frac{\langle0|B^{2j}|0\rangle}{a_0}.
}
\tag{18}
\]

Это второй путь к формулам моментов, без разложения исходного знаменателя. Самосопряжённость исключает комплексные собственные частоты с положительной мнимой частью. Положительная спектральная мера и симметрия относительно смены знака частоты обеспечивают положительность спектра.

Правильная функция с положительной мнимой частью в верхней полуплоскости:

\[
H(z)=-zg(z),\qquad \operatorname{Im}H(z)>0
\quad(\operatorname{Im}z>0).
\tag{19}
\]

Действительно, при спектральной мере \(d\mu_B(\lambda)\) для состояния \(|0\rangle\) и \(\langle B\rangle=0\),

\[
H(z)=\frac1{a_0}
\int\frac{\lambda^2}{\lambda-z}\,d\mu_B(\lambda).
\]

Каждое слагаемое имеет неотрицательную мнимую часть. Утверждать тот же знак для самой \(g(z)\) на всей полуплоскости было бы неверно.

Численная конечная матрица заменяет непрерывную часть множеством дискретных линий. Эти линии не являются дополнительными физическими модами: они служат аппроксимацией резольвенты. Сравнение последовательных размеров матрицы проверяет её сходимость к (1).

### Контрпример за границей

При \(F_0=-1{,}5,r=0\) положительность статической энергии нарушена. На мнимой оси \(L(iy)=y\arctan(1/y)-1\), и условие \(D(iy)=0\) имеет решение

\[
y=0{,}251725366648523614\ldots>0.
\]

Это растущая мода при выбранном временном соглашении. Контрпример показывает, что ограничение \(F_0>-1\) содержательно, а не является декоративным фильтром.

Более того, существование растущего полюса при \(F_0<-1\) не ограничено этим примером. Для любого конечного \(r\ge0\) непрерывная функция

\[
D(iy)=1-(F_0+3ry^2)[y\arctan(1/y)-1]
\]

имеет пределы \(D(i0^+)=1+F_0<0\) и \(D(i\infty)=1+r>0\). Следовательно, она обращается в ноль при некотором \(y>0\); числитель \(L(iy)\) при конечном \(y\) не равен нулю и не сокращает этот полюс. Так граница статической кривизны оказывается и точной границей появления растущей моды в рассматриваемом замыкании. Случай \(F_0=-1\) — отдельная маргинальная граница с расходящейся статической восприимчивостью.

При этом доказанная стационарная аналитичность ещё не означает релятивистскую причинность фронта. Для последней нужен отклик за пределами длинноволнового эффективного окна.

## 9. Что это даёт практически

Непосредственный результат — набор независимых проверок научного расчёта и условных спектральных предсказаний.

Во-первых, неверный знак источника, пропущенная токовая обратная реакция или потерянный вклад отдельного пика можно искать по нескольким согласованным ограничениям, а не по визуальному совпадению графиков. При этом отдельно контролируются очень малые положительные вклады: глобальная малая ошибка интеграла не гарантирует их корректность.

Во-вторых, формула (15) связывает два потенциально независимо извлекаемых свойства коллективного возбуждения: его вес и изменение положения при изменении состояния. Для реального сравнения понадобится определить экспериментальный источник, абсолютную нормировку отклика, связь управляемого воздействия с \(F_0,r\), температурный режим и погрешности.

В-третьих, отношения (11)–(12) могут служить проверкой конкретного двухпараметрического замыкания. Перед их применением к данным необходимо оценить неполноту частотного диапазона и конкурирующие угловые каналы. Контрпример (14) заранее показывает одну из неоднозначностей, которую такая проверка должна исключить.

Ни одна из этих формул не описывает извлечение энергии из вакуума. Для заявления об источнике энергии нужен полный баланс входящей мощности, потерь, внешнего управления и изменения запасённой энергии; спектральный резонанс сам по себе этого не обеспечивает.

Для выбранного источника можно сформулировать более точное ограничение. Если внешняя энергия квазичастицы меняется гармонически с комплексной амплитудой \(U_0\), средняя передаваемая веществу мощность на единицу объёма равна

\[
\boxed{
\overline{\mathcal P}
=-\frac{\omega|U_0|^2}{2}\operatorname{Im}\chi(k,\omega)
=\frac{\pi\omega N_F|U_0|^2}{2}\overline S
\left(\frac{\omega}{kv_F}\right)\ge0.
}
\]

Она получается непосредственно усреднением \(\delta n\,\partial_tU\) за период. В идеальном недиссипативном полюсе выражение понимается как спектральное распределение; для физического воздействия требуется конечная полоса или импульс. Таким образом, этот стационарный сектор модели пассивен: он может принимать энергию внешнего воздействия, но не является ненагнетаемым усилителем. Это ограничение данного режима, а не утверждение о любых неравновесных или внешне накачиваемых системах.

## 10. Чёрные дыры, циклы и предел результата

Спектральная устойчивость однородной стационарной материи не завершает гравитационное действие NVG. Из неё не следует отскок, регулярность чёрной дыры или устойчивость бесконечного числа космологических циклов.

В уже исследованном дополнительном \(\epsilon\)-гравитационном сценарии остаётся явный контрпример автоматической устойчивости циклов: при фиксированных \(\epsilon=0{,}1,R=1\) три из 54 тензорных контрольных мод гиперболичны. Это случаи \((w,n)=(1/3,5),(1,3),(1,9)\); наибольший множитель амплитуды за цикл около \(1{,}181209481\). Одиннадцать исследованных скалярных мод \(\ell=2,\ldots,12\) эллиптичны, что не отменяет тензорных результатов.

Даже у конечномерной системы положительная мгновенная энергия не гарантирует устойчивость при периодическом изменении коэффициентов: сам меняющийся фон может передавать энергию возмущению. Поэтому перенос доказательства из раздела 7 на циклическую космологию без отдельного расчёта монодромии был бы ошибкой.

Следующие действительно необходимые шаги различны: для отклика — согласованные тензорные источники, конечноволновое и столкновительное завершение; для гравитации — вывод требуемых членов из полного действия, все физические моды и нелинейная динамика; для подтверждения — независимые данные с определённой областью применимости. Настоящий результат этой работы — более ограниченная, но значительно лучше проверяемая модель, а не достигнутая универсальная теория.

### Независимое воспроизведение старших определителей

Следующий короткий расчёт не импортирует новый модуль и не использует таблицу результатов плотной материи. Он сравнивает определители, построенные из рекурсии (5), с произведением (8a), используя точные рациональные числа:

```bash
python3 - <<'PY'
import sympy as s

for F, r in [(s.Rational(4), s.Rational(1)),
             (s.Rational(-1, 2), s.Rational(0)),
             (s.Rational(17, 3), s.Rational(7, 5))]:
    A = 1 + r
    c = {}
    for n in range(1, 10):
        c[n] = (s.Rational(1, 2*n+1) + sum(
            (F*s.Rational(1, 2*j+1) - 3*r*s.Rational(1, 2*j+3))
            * c[n-j] for j in range(1, n))) / A
    for N in range(1, 6):
        actual = s.Matrix(N, N, lambda i, j: c[i+j+1]/2).det()
        expected = (1/(6*A))**N
        for j in range(N-1):
            beta = s.Rational(
                (2*j+2)**2*(2*j+3)**2,
                (4*j+3)*(4*j+5)**2*(4*j+7))
            if j == 0:
                beta /= A
            expected *= beta**(N-1-j)
        assert s.simplify(actual - expected) == 0
print("15 exact determinant identities passed")
PY
```
