# Publication status and evidence boundary

**Audit snapshot:** 2026-08-27 (Phase 13)

The tracked article drafts, private `.docs` notes, TeX sources, and PDF
bundles predate the Phase 10 scientific-integrity audit. They are retained as
historical/publication material, not as current computational evidence. Their
numerical claims must not be read as independently confirmed results.

The current executable reference is the canonical runtime ledger generated by
[`verification/run_nvg_suite.py`](verification/run_nvg_suite.py), with the
latest snapshot in [`NVG_FINAL_REPORT.md`](NVG_FINAL_REPORT.md). It reports the
runtime TOV + Hinderer chain and conditional/in-sample comparisons; no global
p-value or held-out confirmation is claimed. Other maintained entry points
label formal calculations, forward models, calibrations, and retired claims
explicitly in their runtime status fields.

The maintained-script boundary and evidence roles are listed in the
[machine-readable registry](verification/registry.json). The ordinary
scientific entry point is [`verification/run_verification.py`](verification/run_verification.py),
which validates registry/provenance, regenerates the canonical ledger, and runs
the semantic pytest suite. [`verification/run_all_checks.py`](verification/run_all_checks.py)
remains a separate process-only smoke harness; its return code is not a
scientific result.

Input provenance and generated-artifact ownership are kept in the
[`provenance.json`](verification/data/provenance.json) and
[`artifact_manifest.json`](verification/artifact_manifest.json) manifests.

The Phase 4 public predictive-research summary is the
[Russian-first public ledger](PREDICTIVE_RESEARCH_LEDGER.md). It preserves
conditional, sensitivity, null, prospective, and `BLOCKED_*` labels; no row
independently confirms the full NVG theory and no global p-value is claimed.

The audited deterministic TXT snapshots
(`nvg_dark_photon_kinetic_mixing_output.txt`, the EM/W-field snapshots, and
`data/nvg_gw_template.txt`) carry a `NON_EVIDENCE_*` provenance header. Other
tracked TXT artifacts remain described by the manifests and are not asserted
to be observational evidence. Tracked HTML dashboards are animation-only,
marked `ILLUSTRATIVE_NON_EVIDENCE` (except the Russian page's explicitly
conditional/in-sample runtime panel), and do not publish independent results.

This status document does not alter article scientific text. Article Markdown
and private `.docs` Markdown carry a short pointer banner; article TeX/PDF
files and unrelated user edits remain untouched. Re-run the named producer
before treating any generated value as a current snapshot, and preserve the
explicit evidence status when redistributing it.
