# NVG: расчёт тепловых колебаний и подготовка к экспериментальной проверке

## Что получилось простыми словами

Прежняя пара моделей W8/U16 теперь рассчитана не только при нулевой
температуре, но и в горячей среде. Без новой подгонки найдены восемь
локально устойчивых состояний и рассчитаны колебания плотности до
четвёртого кумулянта. Сохранены настоящие экспериментальные данные HADES
с опубликованными ошибками — отдельно от результатов модели.

Полезный вывод: отрицательный четвёртый кумулянт возможен и на гладкой
локально устойчивой ветви. Один его знак ещё не доказывает фазовый переход
или новую физику. Экспериментальное подтверждение NVG этим расчётом не получено.

## Какие модели и входы использованы

`verification/nvg_thermal_observable_bridge.py` пересчитывает ту же пару
W8/U16, используя публичный `nvg_nonlinear_calibration_response._build_models`.
Старые калибровочные условия: `y*=.90/.93`, `n0=.16 fm⁻³`,
`E/A−M=−16 MeV`, `K=240 MeV`. Они не перенастраиваются по HADES.
W8 — калиброванный потенциал; U16 добавляет ранее заданную математическую
деформацию, сохраняющую холодные калибровочные условия. Это проверка
различимости моделей, а не вывод новой силы или независимое предсказание
самих калибровочных величин.

Сетка: `T=70 MeV`, `μ=775,875 MeV`, оба якоря, амплитуды деформации `α=0,1`.
В [анализе Vovchenko–Koch, arXiv:2204.00137v3](https://arxiv.org/pdf/2204.00137v3)
у Eq.14 указан диапазон `μ≈750–800 MeV`, а в аннотации и заключении —
`850–900 MeV`. Поэтому взяты обе середины диапазонов, а не точка с более
выгодным результатом. Это условные исследовательские координаты, не
установленные параметры прекращения взаимодействий в столкновении.

Физическая сетка зафиксирована после предварительного теплового расчёта.
Численные настройки уточнялись при реализации; полная предварительная
регистрация всех вычислительных решений не заявляется.

## Термодинамика

Однородная симметричная среда, вырождение `d=4`, естественные единицы:

```
m* = M_N y,    E = sqrt(p² + m*²),    ν = μ − C_v n/y²
f_particle     = 1 / (exp((E−ν)/T) + 1)
f_antiparticle = 1 / (exp((E+ν)/T) + 1)

n  = d/(2π²) ∫ p² (f_particle − f_antiparticle) dp
ns = d/(2π²) ∫ p² (m*/E) (f_particle + f_antiparticle) dp
M_N ns + U'(y) − C_v n²/y³ = 0

P = Pkin − U + C_v n²/(2y²)
ε = εkin + U + C_v n²/(2y²)
```

Интегралы определены от нуля до бесконечности; численные верхние границы
проверяются на сходимость. Вакуумное море не добавляется: сохраняется
исходная конвенция вычитания вакуумной части. Энтропия `s` вычисляется из
энтропий распределений Ферми–Дирака частиц и античастиц.

Проверяются две формы кинетического давления — импульсная и
логарифмическая — и тождества
`ε+P=μn+Ts`, `(∂P/∂μ)_T=n`, `(∂P/∂T)_μ=s`.
Размерности: `n,s: MeV³`, `P,ε: MeV⁴`; перевод в фемтометры использует
`ℏc=197.3269804 MeV fm`.

## Колебания и локальная устойчивость

Система для `z=(ν,y)` дифференцируется неявно до третьего порядка.
Частные производные берутся от вычисляемых интегралов, а не от сохранённой
таблицы. При фиксированной температуре:

```
χ1 = dn/dμ,    χ2 = d²n/dμ²,    χ3 = d³n/dμ³
R21 = T χ1/n,  R32 = T χ2/χ1,   R42 = T² χ3/χ1
```

Это отношения равновесных кумулянтов барионного заряда в большом
каноническом ансамбле. Они не равны автоматически отношениям кумулянтов
числа зарегистрированных протонов.

Для свободной энергии `f(T,n,y)` требуются положительные
`C=f_yy|n` и `f_nn−f_ny²/C`. Сохраняются остатки уравнений, успешные и
неуспешные попытки решения и найденные различные корни. Из устойчивых
корней выбирается ближайший по `y` к холодному якорю. Два стартовых
приближения не обеспечивают поиск всех корней и не доказывают глобальное
равновесие или непрерывное продолжение холодной ветви.

Для редуцированной свободной энергии `f(T,n)`, после исключения поля,
стандартное тождество обратного дифференцирования даёт:

```
R42 = T² [3(f_nnn)² − f_nn f_nnnn] / (f_nn)⁴.
```

При `f_nn>0` числитель всё равно может быть отрицательным. Поэтому
отрицательный `R42` совместим с положительной сжимаемостью. Четвёртый
кумулянт — не четвёртый центральный момент, который неотрицателен.
Это известная термодинамическая связь, не новый универсальный закон.

## Численные результаты

`n` в `fm⁻³`, `P` в `MeV/fm³`; в каждой ячейке W8 / U16:

| `y*` | `μ, MeV` | `n` | `P` | `R42` |
|---:|---:|---:|---:|---:|
| .90 | 775 | .1021793 / .1021798 | 5.700142 / 5.700136 | −.364121 / −.363705 |
| .90 | 875 | .3115189 / .3115164 | 25.799293 / 25.799255 | −.109787 / −.109773 |
| .93 | 775 | .1128630 / .1128631 | 5.790508 / 5.790508 | +.435758 / +.435759 |
| .93 | 875 | .3701394 / .3701392 | 28.083891 / 28.083888 | −.067074 / −.067085 |

Разности `ΔR42=U16−W8` соответственно:
`+4.1570×10⁻⁴`, `+1.3452×10⁻⁵`, `+1.1082×10⁻⁶`, `−1.1310×10⁻⁵`.
Они различимы численно при проведённых проверках сходимости; это не
оценка необходимой точности прибора. Учитывается численная сходимость
обеих сравниваемых моделей.

Проверки включают две точности арифметики, два размера квадратуры и две
границы интегрирования; независимые конечные разности производных;
идеальный ферми-газ, классический предел и знаки античастиц;
приближение к холодным якорям при фиксированной плотности и `T=32,16,8 MeV`.
Последнее проверяет направление сходимости, а не заменяет строгий предел.
Ошибочные входы, неустойчивая ветвь или нарушенные контрольные тождества
не должны превращаться в успешный результат.

## Экспериментальные данные и следующий шаг

В `verification/data/hades_proton_cumulants_2020.json` сохранены восемь
точек Fig.29 с точными опубликованными числами, раздельными
статистическими/систематическими ошибками и происхождением каждой строки.
Источник — [HADES, Phys. Rev. C 102, 024914](https://arxiv.org/abs/2002.08701)
и [HEPData, запись 96305, версия 1](https://www.hepdata.net/record/ins1781493).
Это измерения протонов Au+Au: табличная энергия `√sNN=2.41 GeV`,
`y0=0.74`, `0.4≤pT≤1.6 GeV/c`, два интервала быстроты и две центральности.
Таблица — внешние наблюдения, не подгоночные константы и не вход этого расчёта.

Ковариационная матрица между точками в этой записи не предоставлена.
Но главное препятствие прямому сравнению — разные наблюдаемые величины:
нужен расчёт перехода от барионных колебаний к протонам с учётом состава
материи, движения вещества, области регистрации, сохранения заряда и
флуктуаций объёма. Также необходимо согласовать уже применённые
экспериментальные поправки, а не применять их повторно.

Числа `9.17±.21`, `−33.1±.8`, `691±50` из
[Vovchenko–Koch](https://arxiv.org/abs/2204.00137) — результаты извлечения
характеристик среды в дополнительной модели; указанные интервалы отражают
различие двух окон быстроты. Их нельзя выдавать за полные экспериментальные
ошибки и использовать как независимые стандартные отклонения для NVG.
Здесь не вычислялись `χ²`, значимость совпадения или исключения модели.

## Воспроизведение

Из корня репозитория:

```bash
python3 -B verification/nvg_thermal_observable_bridge.py \
  --output verification/nvg_thermal_observable_bridge_results.json
python3 -B -m unittest verification/test_thermal_observable_bridge.py
```

Расчёт не читает сохранённый файл результатов как физический вход и не
зависит от закрытых рабочих папок. Новые тесты не заменяют проверку всех
исторических расчётов репозитория.
