# Ретардированный отклик при конечном импульсе

## Контрольный вывод

Выполнено новое динамическое продолжение **того же** Dirac/Hartree-фона и
канонического scalar/Higgs–vector действия, без подгонки параметров. Расчёт
имеет нулевой независимый эмпирический вес и является условным
низкоэнергетическим Hartree/RPA-откликом среды с вычитанием фонового
нулеплотностного детерминанта. Это не full vacuum RPA, не спектр конечного
ядра и не глобальное утверждение о положительности спектральной меры.

Главный результат: для исходного Q4 найдены разрешённые действительные
плотностные коллективные полюса вне particle–hole континуума,

| фон, q | верхняя граница particle–hole, МэВ | полюс (s=1), МэВ | вес, МэВ³ |
|---|---:|---:|---:|
| Q4, 100 МэВ | 31.61199 | 46.07243 | 111340.7 |
| Q4, 200 МэВ | 71.86190 | 92.37040 | 218135.6 |

Для коррелированной шкалы `s=1.3` полюса сдвигаются соответственно к
46.07251 и 92.37107 МэВ; это вычисленный эффект канонического градиента, а
не новая настройка. Для W8 `y*=0.90` и `0.93` в каждом из интервалов
`[edge*(1+10^-5), 0.95 q]` полюс не разрешён:
`NONE_RESOLVED_IN_SCANNED_INTERVAL`. Это ограниченное отсутствие не является
теоремой отсутствия при других q и не исключает поглощение в континууме.

## Что именно вычислено

Для `z=omega+i0` использованы угловые примитивы с ретардированной ветвью
логарифма и радиальное разбиение во всех кинематических точках. В ядре
сохранены переходы из занятых положительных состояний как к незанятым
положительным, так и к отрицательно-энергетическим промежуточным состояниям,
требуемым принятым вычитанием. При `q>0` отклик строится из полного блока
`(n,y,A0,A_L)`:

```text
H=[[a,b,g,-g*z/q],
   [b,c0+Z*(q^2-z^2),h,0],
   [g,h,-(q^2+t0),z*q],
   [-g*z/q,0,z*q,t0-z^2]].
```

Общая формула отклика внутри этого приближения:

\[
\boxed{\chi(q,z)=\left[D(q,z)-\frac{B(q,z)^2}{C(q,z)}\right]^{-1}},
\qquad L=t_0+q^2-z^2,
\]
\[
D=a+\frac{g^2(1-z^2/q^2)}{L},\qquad
B=b+\frac{gh}{L},\qquad
C=c_0+Z(q^2-z^2)+\frac{h^2(1-z^2/t_0)}{L}.
\]

Здесь `Z=(s W0)^2`; коэффициенты `a,b,c0,g,h,t0` однозначно заданы
тем же действием, фоном и вычисленными комплексными фермионными интегралами
в [контракте расчёта](verification/contracts/retarded_response.md).
Формула действует при невырожденных исключаемых блоках; в особых точках
нужна полная матрица `H`, а не деление на ноль. Это объединение статического
и динамического откликов данной модели, **не формула всех взаимодействий**.

Прямое решение `H u=(1,0,0,0)` совпадает с аналитическим Schur-выражением
для `chi=delta n/delta mu_ext`. Поэтому `A_L` нельзя заменить простой
подстановкой `q² -> q²-z²`, а смешивание `h` нельзя отбросить: контрольные
варианты без `A_L` и без `h` изменили комплексный отклик Q4 при
`q=100 МэВ, omega=0.6 edge` на 3.43% и 0.302% соответственно.

Всего удержано 48 строк: Q4 при `n0`, калибровочные W8 `y*=0.90,0.93`,
`q=100,200 МэВ`, шкалы `1,1.3` и доли частоты
`0,0.25,0.75,1.25` от живой границы континуума. Комплексные величины
публикуются раздельно как `Re` и `Im`. Например, при `s=1` и `0.75 edge`:

| фон, q | `chi` (МэВ²) | `Im(chi)/pi` (МэВ²) |
|---|---:|---:|
| Q4, 100 МэВ | `6602.76 + 669.06 i` | 212.97 |
| Q4, 200 МэВ | `7280.17 + 1219.95 i` | 388.32 |
| W8 `.90`, 100 МэВ | `-2995.18 + 59103.38 i` | 18813.19 |
| W8 `.93`, 100 МэВ | `-16904.71 + 56533.40 i` | 17995.14 |

Знак соответствует источнику `-delta_mu_ext*n`; для внешнего `+V*n`
отклик имеет дополнительный минус. Положительная мнимая часть здесь —
низкоэнергетическое поглощение в объявленной условной схеме, а не измеренная
ширина.

## Независимые проверки

* Статический предел `omega=0` совпал с поддерживаемым конечным-q
  производителем с максимальной относительной ошибкой `1.1e-13`.
* Аналитическая on-shell мнимая часть `Pi_vv, Pi_vs, Pi_ss` совпала с
  радиальной интеграцией с ошибкой не более `5.1e-15`; за границей
  particle–hole cut мнимая часть не добавляется.
* Два сырых six-component Dirac-current интеграла (порядок Гаусса 256)
  дали Ward-остаток `8.1e-18` для Q4 (`q=100`) и `2.1e-16` для W8 `.90`
  (`q=200`). В искусственно усечённом particle–hole-only базисе нарушение
  было `2.8e-2` и `1.5e-1`, соответственно.
* Для математического UHP-регулятора в точке Q4 `q=100,
  omega=0.6 edge` отклонение от boundary составило 3.79%, 1.91% и 0.96%
  при `eta=.4,.2,.1 МэВ`. Это только проверка сходимости интеграла; `eta`
  не объявляется физической шириной и не остаётся в результате.
* При `q=0, z!=0` плотностной отклик возвращается ровно нулём из сохранения
  полного числа, но удалённый scalar pair-канал сохраняется в `Pi_ss` и
  согласуется с прямым вызовом `polarization_kernel` (он не обнуляется
  искусственно). Точка `q=0,z=0` трактуется как однородная grand-canonical
  статическая восприимчивость с оговоркой о фиксированном N.

Поиск полюсов выполнен на 33- и 65-узловых сетках. Корень принимался только
при конечных `Pi_vv`, `L`, `C`, малом нормированном полном детерминанте и
остатке нулевого вектора, ненулевом перекрытии с плотностью, согласовании
скобки на обеих сетках, а также сходящемся положительном конечном
`-1/(d chi^{-1}/d omega)`. Для смешанно-размерного `H` публикуются raw- и
безразмерные congruence-нормировки с `S=diag(n0,1,W0,W0)` и независимой
проверкой тождества полного детерминанта. Все отклонённые кандидаты остаются
с явной причиной. Сингулярность Schur-фактора или нулевой моды, не связанной
с плотностью, полюсом не считается; поле `regular` означает только численную
разрешимость, а физическая устойчивость не оценивалась.

## Граница интерпретации

Вычитание задаёт `f_-=0` как разность занятостей в объявленной схеме, а не
физический «пустой вакуум Дирака». Не вычислялись полноценно
ренормированные вакуумные коэффициенты, sum-rule completion, столкновения,
спаривание или second-sheet continuation. Поэтому результат ограничен
условным низкоэнергетическим откликом данного усечённого действия. Q4 по
этому расчёту имеет коллективную моду, но это не исправляет ранее известный
провал насыщения; W8 остаётся калибровочной альтернативой, а не наблюдением.
Математически вычтенное ядро не имеет искусственного high-energy cutoff и
может быть вычислено при больших вещественных `z`, но это выходит за
поддерживаемый здесь низкоэнергетический физический scope и не является
глобальным спектральным или stability-утверждением.

Реализация и зафиксированный контракт: `verification/nvg_retarded_response.py`
и `verification/contracts/retarded_response.md`.

## Связь с простой формулой сжимаемости

В длинноволновом бесстолкновительном пределе того же среднего поля условие
отдельной незатухающей моды можно записать через знакомую несжимаемость `K`:

\[
\boxed{K>K_{\rm crit},\qquad
K_{\rm crit}=\frac{3k_F^2}{E_F}\left(\frac{3\mu}{E_F}-2\right)}.
\]

Здесь `E_F=sqrt(k_F^2+M*^2)`, `mu` — полный химический потенциал,
`K=9n dmu/dn`; используются единицы `c=hbar=1`. Это эквивалентная запись
уже полученного в проекте условия `F0>3r`, а не новый универсальный закон:
`N_F=3n E_F/k_F^2`, `F0=N_F K/(9n)-1`, `r=(mu-E_F)/E_F`.
Предпосылки: устойчивая однородная ветвь при нулевой температуре,
положительное векторное взаимодействие, длинноволновое бесстолкновительное
приближение; столкновения, спаривание и полное вакуумное согласование не включены.

| Вариант при `n0` | `K`, МэВ | `Kcrit`, МэВ | Длинноволновое следствие |
|---|---:|---:|---|
| Исходная Q4 | 2063.639 | 348.032 | Отдельная мода, фазовая скорость `0.460479 c` |
| W8 `.90` | 240 | 264.655 | Условие отдельной незатухающей моды не выполнено |
| W8 `.93` | 240 | 235.810 | Формальная мода практически сливается с краем континуума |

У Q4 конечные импульсы дают `omega/q=0.460724` и `0.461852` при
`q=100,200 MeV`: результат согласуется с длинноволновым пределом, хотя
это разные расчёты. Наличие этой моды **не исправляет** провал ядерного
насыщения исходной Q4.

У W8 `.93` формальное относительное отделение от длинноволнового края
`omega/(q v_F)-1 ≈ 1.8e-48`. Это свойство предельного уравнения, а не
разрешимый или устойчивый к поправкам физический сигнал. Оно не противоречит
отсутствию разрешённого полюса в проверенных интервалах при конечных
`q=100,200 MeV`. Заявлять отсутствие мод W8 при любых частотах и импульсах нельзя.

**Понятный вывод:** два вещества могут одинаково сопротивляться медленному
сжатию, но по-разному отвечать на быстрое воздействие. Поэтому одного `K`
недостаточно для выбора модели: динамический отклик содержит дополнительную
информацию об эффективной массе и взаимодействии тока. Это путь к различающему
тесту моделей, ещё не экспериментальная проверка.

Таблица пересчитывается существующими функциями, без подбора новых параметров:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=verification python3 -B - <<'PY'
import mpmath as mp
from source_complete_scaling_saturation_audit import BulkModel, inverse_potential_jet
from nvg_collisionless_response_audit import zero_sound_root
mp.mp.dps = 90
for name, target in (("Q4", None), ("W8 .90", ".90"), ("W8 .93", ".93")):
    if target is None:
        model = BulkModel()
        state = model.equilibrium(model.n0)
    else:
        model, state, _ = inverse_potential_jet(target)
    n, k, ef = (state[key] for key in ("n", "k", "ef"))
    r = n * model.Cv / (state["y"]**2 * ef)
    nf = 3 * n * ef / k**2
    pole = zero_sound_root(nf * state["mu_prime"] - 1, r, dps=90)
    gap = None if pole is None else mp.nstr(pole["gap"], 12)
    speed = None if pole is None else mp.nstr(k / ef * (1 + pole["gap"]), 12)
    print(name, "K=", mp.nstr(state["K"], 12),
          "Kcrit=", mp.nstr(3*k**2/ef*(1+3*r), 12),
          "relative_gap=", gap, "phase_speed/c=", speed)
PY
```


## Воспроизведение динамического расчёта

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=verification python3 -B verification/nvg_retarded_response.py
PYTHONDONTWRITEBYTECODE=1 python3 -B -m pytest -q verification/test_nvg_retarded_response.py verification/test_nvg_nonlocal_response.py
```

CLI заново вычисляет JSON и не перезаписывает результаты. Фокусный набор
содержит 16 прошедших тестов (9 новых и 7 предыдущего статического этапа).
Дополнительное независимое интегрирование подтвердило 36 комплексных точек
и четыре положения полюсов; это численный контроль, не экспериментальная
точность. Полный исторический набор не запускался; три прежние ошибки
связей реестра в капельных материалах остались вне данного изменения.
