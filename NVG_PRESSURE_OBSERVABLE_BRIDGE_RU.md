# Статический мост давления W8/U16

## Назначение и граница

`verification/nvg_pressure_observable_bridge.py` — живой численный мост от
принятого локального различия W8/U16 к одной физически определённой величине:
давлению холодной однородной материи фиксированного состава. Это
**перспективный тест различения двух заранее фиксированных шаблонов**, а не
измерение и не подтверждение NVG. Не вводятся новая сила, новый параметр,
подгонка к эксперименту, конечная температура, конечное ядро, динамический
спектр или третья гармоника.

Каждый запуск заново строит якоря `y*=0.90,0.93` из живого
`source_complete_scaling_saturation_audit.BulkModel` через существующие
`nvg_nonlinear_calibration_response._build_models` и решает стационарный корень
через `_stationary_root`. Таблица результатов не является входом. Принимается
только положительная локальная ветвь с `C_y>0`, `dμ/dn>0`, `y>0` и плотностями
`n/n0=0.80,...,1.20`; номинальное окно старого протокола `0.5..2.0` не
объявляется равномерно устойчивым.

## Определение, единицы и факториалы

Пусть `n_f` задано в `fm^-3`, `n_nat=(hbar*c)^3 n_f` в `MeV^3`,
`e=epsilon/n` в `MeV`, `x=(n_f-n0_f)/n0_f`, `hbar*c=197.3269804 MeV fm`.
Живой код вычисляет

```text
P_nat = n_nat*mu - epsilon       [MeV^4]
P_f   = P_nat/(hbar*c)^3         [MeV fm^-3]
F(x)  = P_f/[n0_f*(1+x)^2]       [MeV] = d e/dx.
```

При насыщении `K=9 e_xx(0)`, `Q=27 e_xxx(0)` и
`Z=81 e_xxxx(0)` (факториалы не поглощены):

```text
e=e0 + K*x^2/18 + Q*x^3/162 + Z*x^4/1944 + ...
F=K*x/9 + Q*x^2/54 + Z*x^3/486 + ...
```

Для `x_i=(-2h,-h,+h,+2h)` и `c=(-1,+2,-2,+1)` используется

```text
Z_h = 81/(2 h^3) * sum_i c_i F(x_i).
```
Суммы коэффициентов с `1,x,x^2` равны нулю, а с `x^3` равна `12h^3`:
контраст удаляет постоянный член, наклон и кривизну **в F**, но не выполняет
произвольную подгонку EOS. Для сырого давления деление на `(1+x)^2` обязательно.
При совпадающих K и Q
`delta(P_f)_{xxx}(0)=n0_f*deltaZ/81`, а кубический коэффициент равен
`n0_f*deltaZ/486`.

Функция `pressure_contrast(...)` принимает ровно четыре конечных давления в
порядке `(-2h,-h,+h,+2h)`, проверяет `n0_f3`, `h`, единицы и опциональную
симметричную положительно полуопределённую ковариацию
`(MeV fm^-3)^2`, и возвращает `Z_h`, веса и `sqrt(w.T Sigma w)` в MeV.
Строковые элементы ковариации разбираются в локальном контексте минимум 80
знаков (более высокая точность вызывающего кода сохраняется), поэтому
корректные PSD-матрицы ранга один и нулевая передача дисперсии не отвергаются
округлением eigensolver при обычной 15-значной точности; существенно
неположительные матрицы по-прежнему отвергаются. Ненулевая ковариация перед
проверкой симметрии и PSD нормируется на собственный максимум модуля, поэтому
положительное масштабирование (включая `10^-120`, `1` и `10^120`) не меняет
решение; нулевая матрица обрабатывается отдельно. Допуск свёртки дисперсии
масштабирован как `||Sigma||_max*||w||^2`, без абсолютного физического пола.

## Чувствительность

Для равных независимых ошибок `sigma_P` **на каждую точку** одной
четырёхточечной серии
`norm(w)=sqrt(sum(w_i^2))`, где
`w_i=81 c_i/[2h^3 n0_f(1+x_i)^2]`. Заранее объявлены односторонние
`alpha=0.05`, `power=0.80`: `sigmaP_max=|deltaZ_h|/[norm(w)*(Phi^-1(.95)+Phi^-1(.80))]`,
`Phi^-1(.95)+Phi^-1(.80)=2.48647486052`. Это идеальная перспективная ошибка
давления **на точку** для одной серии, а не ошибка самого контраста и не
аппаратная неопределённость, не наблюдательная
значимость и не бюджет всех систематик; множитель `sqrt(2)` не используется,
поскольку сравниваются данные с фиксированными теоретическими средними.
Для коррелированных ошибок следует передавать фактическую ковариацию. При
`deltaZ_h=0` API сообщает неидентифицируемость вместо нулевого «достижимого»
бюджета: одинаковые гипотезы не дают требуемую мощность выше уровня ложной
тревоги при любом конечном шуме.

| якорь | h | `delta Z_h` MeV | `delta Z` из живой производной MeV | дифф. Taylor-смещение MeV | `sigmaP_max` MeV fm^-3 |
|---|---:|---:|---:|---:|---:|
| .90 | .10 | 2.2558962592 | 2.1207879107 | .1351083485 | 1.04553e-6 |
| .90 | .05 | 2.1552939513 | 2.1207879107 | .0345060405 | 1.32677e-7 |
| .90 | .025 | 2.1294518819 | 2.1207879107 | .0086639712 | 1.66340e-8 |
| .93 | .10 | .05813303222 | .04849382613 | .0096392061 | 2.69427e-8 |
| .93 | .05 | .05076216052 | .04849382613 | .0022683344 | 3.12484e-9 |
| .93 | .025 | .04905257996 | .04849382613 | .0005587538 | 3.83169e-10 |

`Z_h` при конечном `h` не объявляется несмещённой оценкой Z. В текущем
диапазоне деление h пополам увеличивает норму шумов примерно в `7.53–7.88` и
уменьшает дифференциальное Taylor-смещение примерно в `0.24–0.26`, что
согласуется с асимптотикой `h^-3` и `h^2`, но для принятия фиксированных
шаблонов можно сравнивать точный конечный контраст без Taylor-аппроксимации.

## Применимость к реальному эксперименту

Этот checkout не содержит прямого измерения давления холодной бесконечной
однородной материи и не задаёт аппаратную ковариацию. Давление из потоков
тяжёлых ионов является транспортным выводом с зависимостями от сечений и
коалесценции, а не готовой независимой ошибкой для этой серии (Cozma,
[arXiv:2407.16411](https://arxiv.org/abs/2407.16411); контекст EOS также
Danielewicz–Lacey–Lynch,
[nucl-th/0208016](https://arxiv.org/abs/nucl-th/0208016)). Измеренные STAR
кумулянты протонов до четвёртого порядка относятся к конечной температуре,
приёмке и законам сохранения, поэтому не являются `chi3` холодной модели
(STAR, [arXiv:2504.00817](https://arxiv.org/abs/2504.00817); коррекции
субобъёма у Vovchenko et al.,
[arXiv:2003.13905](https://arxiv.org/abs/2003.13905)). Измерения гигантского
монополя — конечные ядра и силовые функции; текущий статический TF-мост не
является расчётом спектра (Arroyo et al.,
[arXiv:2412.18658](https://arxiv.org/abs/2412.18658)).

Формальная связь `C4/C2=T^2 chi3/chi1` относится к grand-canonical системе при
`T>0`; строки `T=0` здесь нельзя переименовать в STAR-кумулянты. Поэтому
числа выше — только воспроизводимый расчёт разделения/требуемой идеальной
точности для фиксированных шаблонов.

## Воспроизведение

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=verification \
  python3 -B verification/nvg_pressure_observable_bridge.py \
  > verification/nvg_pressure_observable_bridge_results.json
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=verification \
  python3 -B -m unittest -v verification/test_pressure_observable_bridge.py
```

По умолчанию CLI печатает строгий конечный JSON и ничего не пишет; запись
выполняется только с явно указанным `--output`. Публичный Python API:

```python
from verification.nvg_pressure_observable_bridge import pressure_contrast
r = pressure_contrast(
    [p_m2h, p_mh, p_ph, p_p2h], n0_fm3="0.16", h="0.10",
    covariance=sigma4x4,  # optional, units (MeV fm^-3)^2
)
```

Артефакт имеет `evidence_weight=0.0`; это не универсальный EOS, не новая
физика и не подтверждение экспериментальной наблюдаемости.
