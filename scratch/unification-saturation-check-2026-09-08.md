# Проверка насыщения: сертификат исключения и открытая обратная калибровка

Дата: 2026-09-08. Изолированное исследование по `SOURCE_COMPLETE_MODEL_RU.md`; исходные параметры и производственный код не изменены. Естественные единицы, d=4, нулевая температура, однородное среднее поле без вакуумных фермионных петель.

## FOCUS: замысел

Насыщение удобно проверять через неравенство, действующее сразу на всё пространство состояний. Оно отделяет несовместимость исходных параметров с ядерной связью от ошибок поиска ветвей. После такого исключения можно открыто решить обратную задачу для той же функциональной формы, объявив плотность и энергию насыщения двумя калибровочными данными. Исключение двух свободных параметров сводит задачу к одному уравнению эффективной массы. Сжимаемость после этой процедуры остаётся проверяемым следствием формы функционала. Сопоставление с опубликованными родственными моделями позволяет определить, является ли найденная трудность уже известной особенностью такого приближения. Главный риск — принять попадание в два использованных условия за физическое подтверждение или перенести статическое заключение на полный динамический спектр.

## Обозначения и два объявленных условия калибровки

Положим M=939 MeV, W0=859 MeV, mω=782.6 MeV, h=197.3269804 MeV fm,

\[
y=W/W_0,\quad A=\lambda W_0^4,\quad C_v=g_\omega^2/m_\omega^2,\quad C_s=M^2/(2A)=g_s^2/m_\sigma^2.
\]

Здесь Cs имеет размерность MeV⁻² и не обозначает скорость звука. Для перевода Cs,Cv в fm² умножаем на h². Функционал:

\[
\mathcal E=F_F(n,My)+\frac A4(y^2-1)^2+\frac{C_v n^2}{2y^2},\qquad V=C_v n/y^2.
\]

Явно меняются только λ и gω, в отдельной исследовательской задаче. Калибровочные данные: n=0.16 h³ MeV³ и ε/n=μ0=923 MeV при P=0. Последнее равенство μ0=ε/n следует из P=nμ−ε. Значения W0,M,mω и h остаются фиксированными. Никакого изменения сохранённого действия этим не производится.

## Аналитический сертификат для исходных параметров

Если Cv≥Cs, то при **любых** n>0,y>0 имеем E>Mn. Доказательство для 0<y<1 использует FF> Mny и AM–GM:

\[
U+\frac{C_v n^2}{2y^2}
\ge 2\sqrt{\frac A4(1-y^2)^2\frac{M^2n^2}{4Ay^2}}
=\frac{Mn(1-y^2)}{2y},
\]
\[
\mathcal E>Mn\frac{y+y^{-1}}2\ge Mn.
\]

При y≥1 уже FF>Mn, остальные слагаемые неотрицательны. Строгость FF>mn следует из ненулевого ферми-импульса при n>0. Граница сохраняется для объёмных смесей этих однородных состояний с неотрицательными долями; это не доказательство для произвольных новых градиентных взаимодействий или иных составов.

Также на **любой стационарной однородной ветви** P>0, если Cv≥Cs. Для y<1 поле даёт

\[
Ay(1-y^2)=Mn_s-\frac{C_v n^2}{y^3}\le Mn,
\quad
U\le\frac{M^2n^2}{4Ay^2},
\]
\[
P\ge P_F+\frac{n^2}{2y^2}(C_v-C_s)>0.
\]

Для y≥1 используем следовое тождество стационарного функционала,

\[
\varepsilon-3P=A(1-y^2),\qquad
4P=n\mu+A(y^2-1)>0.
\]

Для исходных параметров λ=1.05,gω=10.12:

| Величина | Результат |
|---|---:|
| Cs, MeV⁻² | 0.000000771150659739862576268184813156 |
| Cv, MeV⁻² | 0.000167217350488379081203239197760 |
| Cs, fm² | 0.0300270159558943 |
| Cv, fm² | 6.51109869102713 |
| Cv/Cs | 216.841350488875 |

Следовательно, исходная параметризация не допускает связанную однородную материю или стационарное P=0 при какой-либо положительной плотности. Это утверждение сильнее сеточного результата при n0 и не требует доказательства единственности ветвей. Для y<1 при n0 даже грубая граница n²(Cv−Cs)/(2h³)=16.36979588349 MeV/fm³ положительна, поскольку 1/y²>1 и PF>0.

## Исключение параметров и единственный корень обратной задачи

Обозначим k=(3π²n/2)^(1/3), E=√(k²+M²y²), m=My. Три уравнения:

\[
E+V=\mu_0,\quad P_F-\frac A4(y^2-1)^2+\frac{nV}2=0,
\quad Ay(y^2-1)+Mn_s-\frac{nV}{y}=0.
\]

Из первых двух находим

\[
V=\mu_0-E,\quad C_v=Vy^2/n,\quad
A=\frac{4P_F+2nV}{(1-y^2)^2}.
\]

Подстановка в третье даёт 4y²PF+(1+y²)nV+(y²−1)mns=0. Тождество свободного газа mns=nE−4PF сокращает это до

\[
\boxed{h(y)=\mu_0(1+y^2)-2E+4P_F/n=0.}
\]

При положительном Cv физическая область

\[
0<y<y_{\max}=\frac{\sqrt{\mu_0^2-k^2}}M=0.942199208616158742597643613872.
\]

Единственность здесь доказуема, а не выводится из сетки. При фиксированном n обозначим ⟨1/Ep⟩=ns/(mn); тогда ⟨1/Ep⟩>1/E и

\[
h'(y)=2y\left[\mu_0+\frac{M^2}E-2M^2\langle1/E_p\rangle\right]
<2y(\mu_0-M^2/E)<0,
\]

поскольку E<μ0<M. На левом краю h(0+)=μ0−k>0. На правом краю PF/n≤k²/(5mmax), поэтому

\[
h(y_{\max})\le\mu_0(y_{\max}^2-1)+\frac{4k^2}{5m_{\max}}
=-41.05199280611\ldots\ \mathrm{MeV}<0.
\]

Знак последней границы сохраняется даже при грубом 263<k<264 MeV; он не зависит от последних численных разрядов. Следовательно, ровно один корень существует **в указанной физической области этой обратной задачи**. Сканирование 4096 равных интервалов независимо нашло одну смену знака в [0.780948806946254622,0.781178836049920676]. Это не утверждение об отсутствии иных фаз полного действия.

Cs>Cv проходит необходимое условие для связи, а C>0,μ′>0,0<c_sound²<1 устанавливают локальную статическую устойчивость и субсветовой термодинамический отклик в найденной точке. Полный динамический спектр и глобальная фазовая диаграмма здесь не вычислены. Значение mσ является спектральным следствием канонической нормировки именно данного действия; ему не приписывается экспериментальная идентификация.

Для воспроизведения K в координате y:

\[
H=\mathcal E_{yy}=A(3y^2-1)+M^2\left(3n_s/m-3n/E\right)+3C_v n^2/y^4,
\]
\[
b=\mathcal E_{ny}=M^2y/E-2C_vn/y^3,\quad
D=k^2/(3nE)+C_v/y^2,\quad
\mu'=D-b^2/H,\quad C=H/W_0^2.
\]

K вычислялся после определения параметров; производные берутся при **фиксированных** A,Cv, без повторной калибровки при изменении n. Второй независимый способ — численно дифференцировать дважды стационарную энергию, решая поле для соседних плотностей. При повторном запуске кода из этого Markdown разница двух K составила 9.61×10⁻⁷⁷ MeV при mp80 и 1.98×10⁻¹¹⁸ MeV при mp120. Показанные 52 разряда решения совпали. Невязка поля была 1.06×10⁻⁷¹ и 1.70×10⁻¹¹² MeV⁴ соответственно; давление округлилось к нулю, E/n=923. Эти разряды характеризуют вычисление при фиксированных десятичных входах, а не физическую точность.

В координате y статическая EOS зависит от A,Cv,M. После двух условий насыщения K не изменится от переобозначения W0 с компенсирующей λ=A/W0⁴. Поэтому изменение одного масштаба W0 не является дополнительной ручкой для исправления этого K при сохранении формы и тех же условий калибровки.

## Сопоставление с первичной литературой

Sahu и Ohnishi рассматривают родственный SU(2) chiral sigma functional с динамической векторной массой и дополнительными степенями скалярного потенциала; они вводят дополнительные параметры и используют K≈300 MeV (выбор в 250–350 MeV) при калибровке. Это существенно ниже наших 692.07 MeV. Их модель, её симметрии и связи не тождественны текущему действию. См. [Sahu–Ohnishi, PTP 104 (2000), §2, стр. 4 PDF](https://arxiv.org/pdf/nucl-th/0007068).

Ogawa et al. получают K=650 MeV в другой extended chiral sigma model после настройки насыщения (ρ=0.141 fm⁻³, связь −16.1 MeV), сравнивая с K=281 MeV для TM1 и связывая большую жёсткость с проблемами конечных ядер. Наш результат воспроизводит тип известной трудности, а не подтверждает численное равенство или идентичность моделей. См. [Ogawa et al., PTP 111 (2004), §3, стр. 7 и 9 PDF](https://arxiv.org/pdf/nucl-th/0312042).

Эти исторические сопоставления не задают современный доверительный интервал для эмпирического K. Они показывают, почему совпадения с двумя условиями насыщения недостаточно и почему добавление свободы формы должно проверяться на независимых величинах.

## Воспроизводимый независимый код mp80/mp120

Запуск: `.venv-research/bin/python -` с кодом ниже. Используется только mpmath; производственные EOS/TOV-функции и сохранённые ожидаемые результаты не читаются. Начальный корень задаётся обнаруженным интервалом смены знака, не числом ожидаемого ответа.

```python
import mpmath as mp

for precision in (80, 120):
    mp.mp.dps = precision
    M, W0, mu, mw = map(mp.mpf, ('939', '859', '923', '782.6'))
    hc = mp.mpf('197.3269804')
    n = mp.mpf('.16') * hc**3

    def fermions(nn, y):
        k = (3 * mp.pi**2 * nn / 2)**(mp.mpf(1) / 3)
        m = M * y
        E = mp.sqrt(k*k + m*m)
        ns = m * (k*E - m*m*mp.asinh(k/m)) / mp.pi**2
        P = (k*E*(2*k*k-3*m*m) + 3*m**4*mp.asinh(k/m)) / (12*mp.pi**2)
        return k, E, ns, P

    def root_function(y):
        k, E, ns, P = fermions(n, y)
        return (1+y*y)*mu - 2*E + 4*P/n

    k = fermions(n, mp.mpf(1))[0]
    ymax = mp.sqrt(mu*mu-k*k) / M
    grid = [ymax*mp.mpf(i)/4096 for i in range(1, 4097)]
    brackets = [(a, b) for a, b in zip(grid, grid[1:])
                if root_function(a)*root_function(b) < 0]
    print('precision, brackets', precision, brackets)

    for bracket in brackets:
        y = mp.findroot(root_function, bracket, solver='anderson')
        k, E, ns, P = fermions(n, y)
        V = mu-E
        A = (4*P+2*n*V)/(1-y*y)**2
        Cv = V*y*y/n
        Cs = M*M/(2*A)

        def energy(nn, yy):
            kk, EE, nss, PP = fermions(nn, yy)
            return nn*EE-PP + A*(yy*yy-1)**2/4 + Cv*nn*nn/(2*yy*yy)

        H = A*(3*y*y-1)+M*M*(3*ns/(M*y)-3*n/E)+3*Cv*n*n/y**4
        b = M*M*y/E-2*Cv*n/y**3
        D = k*k/(3*n*E)+Cv/y**2
        mup = D-b*b/H
        K = 9*n*mup

        def relaxed_energy(nn):
            yy = mp.findroot(lambda z: mp.diff(lambda zz: energy(nn, zz), z),
                             (y*mp.mpf('.999'), y*mp.mpf('1.001')))
            return energy(nn, yy)

        direct_K = 9*n*mp.diff(relaxed_energy, n, 2)
        values = dict(y=y, lam=A/W0**4, gomega=mp.sqrt(Cv)*mw,
                      A=A, Cs_fm2=Cs*hc**2, Cv_fm2=Cv*hc**2,
                      mstar=M*y, msigma=mp.sqrt(2*A)/W0,
                      C=H/W0**2, muprime=mup, K=K,
                      soundspeed2=n*mup/mu,
                      field_residual=mp.diff(lambda z: energy(n, z), y),
                      P_residual=P-A*(y*y-1)**2/4+n*V/2,
                      E_per_n=energy(n, y)/n,
                      K_difference=direct_K-K,
                      H_difference=mp.diff(lambda z: energy(n, z), y, 2)-H)
        for name, value in values.items():
            print(name, mp.nstr(value, 52))

    A0 = mp.mpf('1.05')*W0**4
    Cv0 = mp.mpf('10.12')**2/mw**2
    Cs0 = M*M/(2*A0)
    print('original Cv/Cs', mp.nstr(Cv0/Cs0, 40))
    print('original n0 pressure bound for y<1',
          mp.nstr(n*n*(Cv0-Cs0)/(2*hc**3), 40))
```

Итог исследования: строгий сертификат исключает ядерную связь у исходных параметров; открытая двухпараметрическая калибровка той же формы даёт K≈692 MeV. Это конкретный проверяемый диагноз формы и параметров модели, без заявления о новой фундаментальной теории или новой эмпирической закономерности.
